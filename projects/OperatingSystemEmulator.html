Operating System Emulator

My Operating System Emulator (OSEM) was developed using C++. The OSEM simulates core operating system functions, which include process representation, process scheduling, multi-core CPU execution, and memory management. First-Come First-Served (FCFS) and Round Robin (RR) scheduling algorithms were implemented for process execution. A first-fit memory allocator was also built for process allocation and deallocation. The OSEM executes processes in a multithreaded manner where threads are simulated as CPU cores to execute processes concurrently while tracking each process's lifecycle. A command-line interface (CLI) was designed and is utilized to monitor CPU and memory utilization, process states, execution logs, and overall scheduler activity in real time.
