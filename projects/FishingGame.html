Android Fishing Game

ReelySDV (Really StarDew Valley) was a passion project mixed with my major requirement for my mobile development class. We were given free rein to pick whatever we did for our final output for the subject, so long as it was a mobile application. I took this as an opportunity to do something fun, which was to make a game! At the start of the semester, I got really hooked on Stardew Valley, specifically the fishing minigame. While my friends would tend to the farm and livestock, I would be by the ocean fishing away from dawn till dusk. When I proposed this project to my professor, he suggested that I use Godot, a lightweight open-source game engine, instead of using Android Studio (which was the main IDE used for the subject). The game features fishing mechanics inspired by Stardew Valley, and a leaderboard whose scores are read and written locally.
