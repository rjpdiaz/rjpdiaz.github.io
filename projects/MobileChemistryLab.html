Mobile Chemistry Lab

The Mobile Chemistry Lab is a 3D virtual chemistry lab that was developed with the Unity game engine. The goal of the application was to provide public schools (specifically high schools) with alternatives for teaching chemistry, since maintaining a laboratory was costly. To achieve this, we leveraged the fact that the majority of students nowadays have smartphones. However, this doesn't guarantee that their phones would be strong enough to run a graphically intensive application. Thus, we made the application as lightweight as possible. One method used to achieve this was to optimize the geometry of each 3D asset to use the fewest polygons while maintaining an accurate figure. We also restricted the amount and intensity of lighting used. The application features a 3D environment, activity creation, activity editing, activity sharing through Bluetooth, performance visualization of the experiment proper, and, of course, the ability to perform experiments.
