Interactive Island

The 3D Interactive Island was a project for my 3D modeling elective. It is a web-based application that was built using html, css, and javascript. Vite was also used as the build tool and development server, with npm managing project dependencies. The application features a Japanese-inspired 3D island with a functioning vending machine that dispenses drinks and displays the drink's data.
